# Common Mode Return Currents
Common in Power Electronics, such as having a heat sink connected to a switching MOSFET

2 cases: 
- Heatsink is electrically connected to MOSFET
If it has long fins -> basically becomes antenna -> Hella EMI

- Heatsink is electrically isolated from MOSFET
It basically becomes a capacitor -> current needs to also return somehow -> Find a way to minimize the loop
