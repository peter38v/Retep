# Return Paths in Circuits

![[Pasted image 20260930113732.png]]

At DC current will return based on the ratio of the resistance of thin vs thick conductor

At AC impedance is defined by the inductance as well (Z = omega*L), inductance is related to the loop area.

Thus larger loop, larger impedance -> naturally will go path of least resistance
