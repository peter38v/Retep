# Return Current Loops

Smaller Area loops have a lower Inductance -> Lower EMI -> Lower Impedance

$$
L ~= \mu(\frac {D}{2})*(ln(\frac {8*D}{d})-2)
$$

where: \
D = Diameter of loop \
d = diameter of thickness of loop
